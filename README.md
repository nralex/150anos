# 150 anos da construção da Matriz — Landing Page Oficial

Landing page comemorativa desenvolvida para celebrar os **150 anos da construção da Igreja Matriz de São Raimundo Nonato**, pertencente à Diocese de São Raimundo Nonato — PI.

O projeto foi pensado para transmitir um visual:

* solene
* elegante
* histórico
* acolhedor
* responsivo
* fácil de manter

A identidade visual utiliza como base o vermelho mártir e o dourado litúrgico presentes na campanha oficial dos 150 anos.

---

# ✨ Recursos da página

* Hero section institucional
* História da Matriz
* Programação comemorativa
* Área de doações via PIX
* Galeria de fotos
* Rodapé institucional
* Layout responsivo
* Animações suaves com CSS
* Estrutura simples em HTML/CSS/JS puro
* Código totalmente comentado para fácil manutenção

# 🖼️ Como trocar imagens

Todas as imagens podem ser alteradas diretamente no arquivo `index.html`.

Procure por:

```html
src="https://placehold.co/..."
```

e substitua por:

```html
src="img/nome-da-imagem.jpg"
```

---

# 🎨 Como alterar cores

As cores principais estão no topo do CSS:

```css
:root{
  --vermelho:#B80D0D;
  --dourado:#F0C93D;
}
```

---

# ✏️ Como editar textos

Todos os textos estão diretamente no HTML para facilitar manutenção.

Exemplo:

```html
<h1>
  150 anos da construção da Matriz
</h1>
```

---

# 🔗 Como alterar links

Substitua os valores de:

```html
href="#"
```

por:

```html
href="https://..."
```
