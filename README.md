## ✠ Sobre o projeto

Este projeto foi criado para representar visualmente as celebrações jubilares dos **150 anos da construção da Matriz de São Raimundo Nonato**, reunindo memória histórica, identidade religiosa e comunicação institucional em uma experiência digital elegante e acessível.

A proposta visual busca transmitir:

* solenidade
* acolhimento
* tradição
* identidade diocesana
* valorização histórica e cultural

# 🖼️ Como trocar imagens

1. Crie a pasta:

```bash
/assets
```

2. Adicione as imagens desejadas.
3. Procure no `index.html` por:

```html
src="./assets/"
```

4. Substitua pelos nomes corretos dos arquivos.
